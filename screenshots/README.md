# SaadPay

A digital wallet Android app for sending, loading, and managing money — built with a clean, card-based UI and real-time transaction tracking.

## Features

- **Wallet Home** — View available balance and recent activity at a glance
- **Send Money** — Transfer funds instantly to any recipient via email
- **Load Money** — Top up wallet balance in one tap
- **Virtual Card Management** — View card details and toggle withdraw, international, and in-shop purchase permissions
- **Profile & Security** — Fingerprint login, PIN management, and account settings
- **Transaction History** — Filterable history with date range and PDF export


Open in Android Studio, sync Gradle, and run on an emulator or device.
